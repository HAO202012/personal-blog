# research/user 用户与场景

## 用户画像
单作者（站长本人）：写技术/生活随笔，读者通过链接访问。

## 核心使用旅程
- 作者：登录后台 → 写 Markdown → 存草稿或发布 → 归类打标签 → 偶尔修改/删除。
- 读者：进首页浏览最新文章 → 点进详情阅读 → 按分类/标签找同主题 → 用归档按月回看 → 关键词搜内容。

## 内容类型（来源：S2 旅程反推）
- 技术文章：含代码块，需代码高亮
- 随笔：纯文本为主
- 单篇篇幅 500–5000 字

## 验收级用户诉求
1. 发布后前台立即可见（无构建步骤）
2. 草稿不对外可见
3. 手机上阅读体验可接受（响应式）
4. 后台操作 ≤3 步完成发布
